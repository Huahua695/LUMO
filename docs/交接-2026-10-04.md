## 8. 环境坑（Windows + Git Bash，全部踩过）

- MSYS 的 `/tmp` 路径**原生 `ffmpeg.exe` 看不见** → 用 ASCII 暂存目录 **`E:\bench_tmp`**
- Windows 用户名 `Admin（无密码）` 含**全角括号**，会打断 `sed` 与路径处理 → 同上
- Git Bash **没有 `bc`** → 计时用 Python
- `-f null -` 在 Windows 上必须是 **`-f null nul`**
- image2 muxer **要求输出目录已存在**
